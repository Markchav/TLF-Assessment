# TLF Apparel – Product Page Assessment

This project is a responsive product page built using React Router (Framework Mode) and TypeScript.

## Features

- React Router v7 route configuration
- Loader-based API data fetching
- Fully responsive desktop and mobile layouts
- Mobile swipe image carousel with progress indicator
- Color and size selection with state management
- Disabled add-to-bag logic until size selection
- Collapsible product sections
- Tailwind CSS styling

## Tech Stack

- React Router (Framework Mode)
- TypeScript
- Tailwind CSS
- Vite (via React Router CLI)
